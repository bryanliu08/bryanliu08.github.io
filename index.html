Research & Projects

Paper · ICLR 2027 submission 01

FOMO: Forecasting with Other Markets' Observations

A training-free way to make time-series foundation models use related series. By restricting cross-series attention to the late layers, FOMO improved forecasts in every one of 15 model-and-dataset settings and cut worst-decile loss by a median 5.3×. I'm first author.

Time-series · Foundation models · Attention Code on request
Paper · AI safety · ICML 2027 target 02

Strategic Silence in Multi-Agent LLM Systems

When an agent can help but chooses not to speak, that's a form of deception. I measure strategic silence in multi-agent LLM settings and show how it emerges from incentives, with implications for monitoring and alignment.

AI safety · Multi-agent · LLM agents GitHub ↗
Open-source framework 03

WordPlay

A simple way to build multi-agent RL environments for LLMs. I help build and maintain it. Environments are plain Python classes with composable entity components and readable text observations, so a 2,000-line Melting Pot substrate becomes about 300 lines. Powers a 57-scenario benchmark of LLM coordination and social reasoning.

MARL · LLM agents · Python GitHub ↗
Simulator + benchmark · in progress 04

TFT_SIM

An open, data-driven Teamfight Tactics simulator I'm building for RL and LLM agents on top of WordPlay. A new set is a data rebuild, not new code. The question I care about: can agents discover a game's meta before humans do? Targeting NeurIPS Datasets & Benchmarks.

RL · Game AI · 8-player Private until release
Research · credit assignment 05

PACCA: Path-Specific Counterfactual Credit Assignment

My method for crediting each agent in a tool-using LLM team by splitting its effect on the team reward into direct and teammate-mediated parts, then uses that credit as the advantage in GRPO/PPO training. Validated on synthetic SCMs and replicated on real API agents.

Multi-agent RL · Causal inference · GRPO Code on request

Sandbagging under RLVR

My mechanistic interpretability work on sandbagging in reasoning models trained with verifiable rewards: behavioral evidence, partial-identification bounds, and circuit attribution on frontier models.
